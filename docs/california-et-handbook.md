# California Electrician Trainee (ET) Theory Guide

This document summarizes state regulatory expectations for Electrician Trainees operating under California Labor Code Section 108.

---

## 1. Regulatory Framework

- **Enforcement Authority:** California Department of Industrial Relations (DIR), Division of Labor Standards Enforcement (DLSE).
- **Registration Mandate:** Trainees must be actively enrolled in a state-approved curriculum school or apprenticeship program.
- **On-the-Job Supervision:** Trainees must work under the direct, constant supervision of a certified general electrician or certified residential electrician.
- **Code Standard:** California Electrical Code (Title 24, California Code of Regulations, Part 3), adopting the National Electrical Code (NEC / NFPA 70) with California amendments.

---

## 2. Core Trade Formulas

1. **Ohm's Law:**
   $$V = I \times R \quad (V\text{ in volts, } I\text{ in amperes, } R\text{ in ohms})$$
2. **Single-Phase Power:**
   $$P = V \times I \times \text{PF} \quad (P\text{ in watts, } V\text{ in volts, } I\text{ in amperes})$$
3. **Three-Phase Apparent Power:**
   $$S = \sqrt{3} \times V_L \times I_L \quad (S\text{ in volt-amperes, } V_L\text{ in line volts, } I_L\text{ in line amperes})$$
4. **Continuous Load Ampacity Requirement:**
   $$I_{\text{design}} = I_{\text{non-continuous}} + 1.25 \times I_{\text{continuous}}$$
